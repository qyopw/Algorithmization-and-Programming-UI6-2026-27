# Алгоритмизация и Программирование

Репозиторий предназначен для козеров Бауманки. Номер варианта автора - 8.

# Структура проекта

В файле "Input-main.txt" содержится номер задания, которое запускает программа. Если запускаете лабу - введите перед номером "7". Например; 2-ая лаба = 72, 3-я домашка = 3.

Изменение номера семестра пока не добавено, но оно будет в дальнейшем.

Под каждое задание есть свой файл .cpp + .txt, во втором содержася данные на вход программы. Это сделано для того, чтобы было удобно проверять разные входные данные, не перезапуская каждый раз программу целиком.
